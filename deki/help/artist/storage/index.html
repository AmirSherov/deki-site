Хранилище: подключить приватный канал

Хранилище — ваш приватный Telegram-канал, через который вы загружаете музыку и клипы. Без него Студия не работает.

Deki не хранит ваши файлы у себя — они остаются в вашем канале. Канал-хранилище — это рабочее место: вы публикуете туда треки и клипы, а бот присылает туда же статусы загрузки. Подписчики его не видят.

Зачем нужен отдельный приватный канал

  • Файлы остаются у вас. Удалите сообщение с треком — трек пропадёт и из Deki.
  • Это привычно. Загрузка — это просто пост в канале, с телефона или компьютера.
  • Слушатели не видят черновики. Поэтому хранилищем может быть только приватный канал.

Как подключить

  1. Создайте в Telegram приватный канал. Название любое, например «Deki · хранилище». Подписчики не нужны.
  2. Откройте Deki → Студия → Каналы и нажмите Подключить хранилище.
  3. Выберите канал в окне Telegram. Бот станет администратором с нужными правами — ничего настраивать вручную не нужно.
  4. Вернитесь в Deki. Через пару секунд канал появится со статусом Подключено, а бот закрепит в канале приветствие.
Канал должен уже существоватьКнопка открывает в Telegram выбор существующего канала — создать новый из этого окна нельзя. Сначала создайте канал, потом нажмите кнопку.

Права бота

Бот получает права автоматически при подключении. Если позже их поменять, Deki покажет предупреждение на экране «Каналы».

ПравоЗачем
Публикация сообщенийОбязательно. Без него канал теряет роль хранилища.
Редактирование сообщенийЖелательно — бот обновляет свои служебные сообщения.
Удаление сообщенийРекомендуется — бот убирает устаревшие статусы.

Права меняются в Telegram: канал → Администраторы → Deki.

Если что-то пошло не так

Что видитеЧто сделать
«Ваше хранилище публичное»Сделайте канал приватным: канал → Изменить → Тип канала → Частный.
«Хранилищем может быть только приватный канал»Вы выбрали публичный канал. Его можно сделать витриной, а для хранилища создать отдельный приватный.
«Канал отключён» в уведомленияхБота удалили из канала или забрали право публикации. Нажмите Подключить хранилище ещё раз.

Сменить или отключить хранилище

На экране Каналы нажмите на канал: там можно сменить роль, проверить права бота или отключить канал (бот выйдет из него). Хранилище может быть только одно. Новый канал можно назначить хранилищем вместо старого — старый останется подключённым без роли.

Без хранилищанельзя загружать треки и обложки, а значит и создавать релизы. Уже вышедшая музыка при этом остаётся у слушателей, пока сообщения с файлами есть в старом канале.
